# Confidential Swap (gnark vs Xark) -- Benchmark

Generated by `python3 test-utils/compare-benchmarks.py swap`; do not edit.

Side-by-side view of [`gnark/BENCHMARK.md`](gnark/BENCHMARK.md) and [`xark/BENCHMARK.md`](xark/BENCHMARK.md), which their `bench_cu` tests generate in the shared format; see either file for the methodology. Delta is Xark minus gnark, with the percentage of the gnark value. The shielded-pool program differs between the implementations, so `SPP CPI CU` is not an apples-to-apples comparison; `Verify CU` and the circuit metrics are. Warm proving time is one full call of each implementation's prove function, which for Xark 0.3.0 includes per-proof setup (re-reading the circuit and rebuilding its constraint rows) and decoding the proving key from disk; in-memory proving time holds both in memory and is the prover-to-prover comparison. Timings from runs on different machines or under different load do not compare.
