# Timelock Escrow (gnark vs Xark) -- Benchmark

Generated by `python3 test-utils/compare-benchmarks.py escrow`; do not edit.

Side-by-side view of [`gnark/BENCHMARK.md`](gnark/BENCHMARK.md) and [`xark/BENCHMARK.md`](xark/BENCHMARK.md), which their `bench_cu` tests generate in the shared format; see either file for the methodology. Delta is Xark minus gnark, with the percentage of the gnark value. The shielded-pool program differs between the implementations, so `SPP CPI CU` is not an apples-to-apples comparison; `Verify CU` and the circuit metrics are. Timings from runs on different machines or under different load do not compare.
