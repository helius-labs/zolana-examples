# Stake Pool Intents

Private SOL staking on SPP. Users lock SOL or liquid staking tokens in confidential escrow UTXOs with an encrypted intent; once per epoch a crank matches deposits against withdrawals per hash chain, runs one net `DepositSol` or `WithdrawSol` on the stake pool, and pays out confidential UTXOs. [spec.md](spec.md) is the specification.

## Layout

| Directory | Contents |
| --- | --- |
| `program/` | The pinocchio program: config, epoch, batch, intent, cancel, and settlement instructions; committed verifying keys. |
| `prover/` | Rust bindings to the gnark circuits in `prover/circuits/` (intent, cancel, settlement) and the key setup binary. |
| `sdk/` | Note formats and encryption, proof witness builders, the settlement builder, instruction builders. |
| `test/` | Mollusk tests against the real SPP program, the mainnet stake pool program, and the SPP prover. |
| `scripts/` | Dependency checkout, program builds, mainnet program dumps, SPP key prefetch. |

## Build and test

Zolana is pinned to the revision in `Cargo.toml`; `scripts/prepare-deps.sh` checks it out into `.deps/zolana` for the Go circuits and the SPP binaries.

```sh
bash scripts/build-tests.sh      # zolana CLI, SPP prover, SPP and staking programs (SBF)
bash scripts/dump-stake-pool.sh  # stake pool, token, and stake programs from mainnet
bash scripts/fetch-spp-keys.sh   # SPP proving keys for the 2x2, 16x2, and 1x16 shapes
cargo test --workspace
(cd prover/circuits && go test -timeout 30m ./...)
```

The tests generate missing circuit keys into `build/gnark/<circuit>/` on first use (the settlement setup takes a few minutes and about 7 GB). After changing a circuit, regenerate its keys and commit the verifying key:

```sh
rm -rf build/gnark/settlement
cargo run -p private-staking-prover --bin setup -- settlement build/gnark/settlement \
    --rust-vk program/src/verifying_keys/settlement.rs --insecure-test-keys
```

The committed keys come from an insecure, reproducible setup, so they are for tests only. `prover/tests/vk_matches_pk.rs` fails when a committed key no longer matches its proving key.

Go tests solve the settlement circuit against witness fixtures generated by the SDK:

```sh
cargo run -p private-staking-sdk --example settlement_fixture
cargo run -p private-staking-sdk --example encryption_fixture -- payout > prover/circuits/testdata/payout-encryption.json
```
